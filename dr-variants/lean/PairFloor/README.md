# PairFloor: the pair floor for a DR finish, in Lean 4

Lean 4.35.0, no Mathlib, no `native_decide`. It uses the cube model of `judging-a-dr/lean/DRBound` (`DRBound.Cube`: positions, the ten DR moves as tables, states), the one the exact table of optimal DR finishes is certified on.

## What is proved

A *true pair* is a corner and a U/D-layer edge next to each other in the same layer, joined as on a solved cube. A state has 0 to 16 of them (`pairs`).

| Theorem | Statement |
|---|---|
| `pairs_step` | One DR move changes the number of true pairs by at most 4 if it is a side half turn (R2 L2 F2 B2), and not at all if it is a U or D move. |
| `pairs_move_ud` | U and D moves, quarter or half, keep the number of true pairs. |
| `pairs_of_lsSolved` | With the corners and the U/D-layer edges solved there are 16. |
| `pair_floor` | If `g.apply w` has its corners and U/D-layer edges solved, then `16 ≤ pairs g + 4 * sideCount w`. |
| `pair_floor_length` | The same with the total length of `w`: a finish of n moves needs at least 16 − 4n pairs. |
| `pair_floor_full` | The same for a full solve. |

The four `example`s at the end of `Floor.lean` show the floor is reached: `R2` (12 pairs), `R2 L2` (8), `R2 L2 F2` (4), `R2 L2 F2 B2` (0).

## Files

- `PairFloor/Pairs.lean`: the definition of a true pair and of `pairs`. This is the file to read to check that "pair" means what a solver means.
- `PairFloor/Steps.lean`: generated by `gen_steps.py` from the move tables. For each move: where the pieces of the 16 slots come from (`moved_*`, by `rfl`), which slots are carried as a whole (`carried_*`, by `decide` over all 64 corner/edge pieces), and the step bound (`step_*`).
- `PairFloor/Floor.lean`: the theorems above.
- `PairFloor/Audit.lean`: `#print axioms`; the theorems depend on `propext`, `Classical.choice` and `Quot.sound` only.

## Build

    source /data/fmc/env.sh
    cd /data/fmc/dr-variants/lean/PairFloor && lake build      # about half a minute once DRBound.Cube is built

## Not in Lean

- The two refinements for HTR states (10 pairs need 3 moves, 2 pairs need 5): exact over the 663,552 HTR states, computed by `drvar metahtrpairs`.
- That the number of true pairs is the same on the inverse of a state: checked on every state of the study's sample, with the one-line reason that a pair is a block and a block stays a block on the inverse.
